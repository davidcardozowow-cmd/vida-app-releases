# Vida — versões do app

Aqui ficam apenas as versões publicadas (APK) do **Vida**, o app pessoal do David.

- `latest.json`: diz qual é a versão mais nova, onde baixar e a impressão digital (SHA-256) do arquivo.
- `apk/`: os arquivos APK de cada versão.

O app consulta o `latest.json` ao abrir e oferece a atualização. O código-fonte, a chave de assinatura e os dados do usuário **não** ficam neste repositório.
